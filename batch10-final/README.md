## 放入点读笔

Mac 点击上表 BNL 下载链接即可，文件应以 `.bnl` 结尾。拷入毛毛虫点读笔的 `BOOK` 文件夹，安全弹出并重新开机。同一本若已有旧 BNL，请先移到电脑备份，BOOK 中保留所需的新版本，避免重复书目。原始 BNF、ZIP 和旧成品保留备份；不要只改后缀，也不用保存网页。

## 游戏规则与保留内容

253 道单目标问题按三次机会处理：每个原入口保留自己的完整原题库，每轮选一道；第一次错播放本题适用原提示 A，第二次错播放已确认的 B，第三次 B＋退出；任何一次答对立即播放该答案的完整原回复及成功结束音。重新点击入口执行原固件的游戏重置，恢复次数并重新选题。原入口只有一题时保留这一题，不跨页混题。

另外 14 道多目标题保留找齐或指定数量的玩法，包含《面包镇》一道从五个可接受点位中找三个目标的题。需要计数的回复按实际找到的第几个目标播放；按对象回复的游戏保留各自回复。重复点击同一物理点位不增加找到数量。

无单独回复字段的正确点位均保留；每本原有录音、普通点读、两处多音频点读序列和三处原始静音点位均保留。百科原有三种正确提示均可选择，一轮只选一种，未拼成一轮连播三句。

原回复已包含正确提示时不再添加额外提示；确实缺少时才使用用户确认的本书原有正确短音效。生活篇和百科的成功结束语按用户逐项确认使用；B 与退出在各书原包中均找到了与此前确认录音完全相同的 MPEG 内容，使用各自原包里的录音。

原始音频库的 4,743 段 MPEG 帧全部保留，不重压原录音。59 个派生音轨用于合并原完整回复与必要提示、或合并原总结与结束语；只有格式不一致的短附加提示副本被重编码以保证同一派生流稳定，原轨仍完整保留。
